## Featured Projects

### EFR Rover
A passion project serving multiple disciplinaries teaching me essential skills and new software such as 3D modelling in OnShape hands-on assembly of electronics using perforated boards. Designing custom boards on KiCAD, sensor fusion paired with Unitree L3 LiDAR for point cloud mapping ROS2.

- **Tools and technologies:** OnShape, KiCAD, Arduino ESP32, Raspberry Pi 5, & 3D Point Cloud Mapping.
- **Key challenge:** Overall lifecycle maintenance
- **Result:** Partial mapping using 3D point cloud scans of my school paired with an edge compute device. Succesful outdoor trials lasting  hours in various terrains (sand, gravel, tall grass, and pavements).
